# Squad Studio

The [7 October card/dashboard revision](player-card-design.md) supersedes the
original card captions, selected-player actions, settings and summary layout
described below. Current mapped ST ratings use observed 2025/26 evidence;
chemistry remains illustrative.

Mode: Operate. Audience: a coach or analyst exploring a custom Liverpool lineup.
Sourced men's first-team identities are separate from illustrative ratings and chemistry. Academy/U21 squad rosters are excluded; an under-21 player listed in the men's first team is not excluded by age alone.

## Direction contract

THESIS: manage eleven players directly on a pitch; inspection is a drawer, not a permanent analytics sidebar.

OWN-WORLD: graphite, deep turf green, crimson selection, champagne ratings, silver Source Sans 3 lettering; authored shirt silhouettes and consistent player cards.

STORY: choose formation, inspect skill contributions, substitute a player, understand changed links, export the planning record.

FIRST VIEWPORT: compact club controls and lineup summary above a full-width pitch; eleven cards sit above thin chemistry links; the bench opens as a bottom drawer. Small screens scroll to preserve legibility.

FORM: approved football-management game reference overrides the concept roll; seed scout-squad-20261006, grounded direction 6, training/selection studio.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Quality bar / implementation boundary

- Make direct squad operations understandable from the pitch and persistent selected-player controls.
- Give ratings, names and positions a stable card hierarchy; maintain a restrained premium football-management visual language.
- Use authored SVG shirts and initials. No generated faces, copied game artwork or unlicensed player portraits ship.
- Keep source facts, manual roles and demonstration measurements visibly distinct in cards, drawers and exports.
- Preserve eleven identities across formations and offer pointer, tap and keyboard alternatives without hidden score penalties.
- Provide responsive layouts, reduced motion, recoverable local storage and authoritative evaluation. Large analysis stays in drawers.

This is a code-led build against the approved written plan and supplied game reference; no approved raster comp exists. Any earlier comp-led build-state artifact belongs to the prior workbench work and is not a gate for this dashboard.
