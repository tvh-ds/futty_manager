# Execution and cost report

Cloud spending in this workspace: **none performed or verified**. No Azure/Databricks accounts are configured. Credits, subscription eligibility and free provider rights are unverified, not assumed.

The locally executed workload is small: 240 fictional player stints for the product workflow; a separate historical sample of 34 matches/916 shots for research. Classical training fit in under a second per model and the bounded MLP in about 1.6 seconds for the observed CPU run; artifact logging adds overhead. Spark is a platform-learning path, not a necessity established by this sample's size.

Azure defaults: Container Apps minimum zero/maximum one replica; Static Web Apps Free; private LRS storage; sampled telemetry with daily caps/30-day logs; configurable budget notification. These settings still permit costs. Quotas/free grants, cold starts and service eligibility need actual account verification. Never describe the deployment as permanently free.

The credit guard is a recent manual-portal-attestation gate. It does not query a live balance and does not cap Azure spending. Scheduled ingress shutdown stops public requests and allows a zero-replica app to idle; storage/telemetry persist. A verified shutdown drill, daily cost measurement and cleanup/retention policy remain prerequisites for enabling cloud workflows.
